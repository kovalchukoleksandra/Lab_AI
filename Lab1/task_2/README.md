Task 2 — Система розпізнавання образів

Завдання
Створити систему розпізнавання образів за допомогою нормованих векторів ознак та методу порівняння з еталоном.

Опис роботи
Програма створює вебінтерфейс за допомогою Gradio.

Користувач може:

1.Завантажити 4 еталонні зображення.
2.Отримати абсолютний та нормований вектори для кожного еталону.
3.Переглянути зображення із сіткою 5×5.
4.Завантажити невідоме зображення.
5.Отримати його абсолютний та нормований вектори.
6.Порівняти невідомий образ з усіма еталонами.
7.Отримати результат класифікації.

 Основна функція `calculate_feature_vector()`

Функція:

* переводить зображення у відтінки сірого;
* розділяє його на 25 областей;
* підраховує кількість чорних пікселів;
* формує абсолютний вектор;
* формує нормований вектор.

 Функція `process_reference()`

Обробляє окремий еталонний образ та виводить:

* абсолютний вектор;
* нормований вектор;
* зображення із сіткою 5×5.

Чебишевська відстань

Для порівняння невідомого образу з еталонами використовується норма Чебишева:
text
d(X,Y) = max |xᵢ - yᵢ|

Функція `chebyshev_distance()` знаходить найбільшу різницю між відповідними елементами двох нормованих векторів.

Функція `recognize_image()`

Функція:

* отримує еталонні та невідоме зображення;
* створює їхні вектори;
* обчислює Чебишевські відстані до кожного еталона;
* знаходить найменшу відстань;
* визначає клас невідомого образу.

 Інтерфейс Gradio

Використано:

* `gr.Blocks()` — основний контейнер;
* `gr.Image()` — завантаження та відображення зображень;
* `gr.Textbox()` — виведення векторів і результатів;
* `gr.Button()` — запуск обробки та розпізнавання;
* `gr.Row()` і `gr.Column()` — розміщення елементів.
