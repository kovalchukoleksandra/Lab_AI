 Task 1 — Побудова вектора ознак

Завдання

Розробити програму для побудови абсолютного та нормованого векторів ознак графічного зображення.

Опис роботи

Програма створює вебінтерфейс за допомогою Gradio.

Користувач може:

1.Завантажити чорно-біле зображення.
2.Натиснути кнопку «Побудувати вектор ознак».
3.Переглянути зображення із сіткою 5×5.
4.Отримати абсолютний вектор ознак.
5.Отримати нормований вектор ознак.

Основна функція `calculate_feature_vector()`

Функція отримує зображення та:

* переводить його у відтінки сірого;
* розділяє зображення на 25 областей за сіткою 5×5;
* підраховує кількість чорних пікселів у кожній області;
* формує абсолютний вектор із 25 значень;
* нормує отриманий вектор;
* створює зображення із сіткою 5×5.

Абсолютний вектор

Для кожної області підраховується кількість чорних пікселів:

python
black_pixels = np.sum(cell < 128)

Отримані значення утворюють абсолютний вектор:
text
X = (x₁, x₂, ..., x₂₅)

 Нормований вектор

Нормування виконується за формулою:
text
xᵢ' = xᵢ / Σxᵢ


де `Σxᵢ` — загальна кількість чорних пікселів зображення.

 Інтерфейс Gradio

Використано:

 `gr.Blocks()` — основний контейнер;
 `gr.Image()` — завантаження та відображення зображення;
 `gr.Button()` — кнопка побудови вектора;
 `gr.Textbox()` — виведення векторів;
 `gr.Markdown()` — заголовки та опис;
 `gr.Row()` і `gr.Column()` — розміщення елементів.

Обробка кнопки

Після натискання кнопки викликається:
python
calculate_button.click(
    fn=calculate_feature_vector,
    inputs=input_image,
    outputs=[
        absolute_output,
        normalized_output,
        grid_output
    ]
)


Результати передаються у поля абсолютного вектора, нормованого вектора та зображення із сіткою.
