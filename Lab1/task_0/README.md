Task 0 — Image Uploader

Завдання

Ознайомитися з фреймворком Gradio та створити простий вебінтерфейс для завантаження і відображення зображення.

Опис роботи

Програма створює вебінтерфейс за допомогою Gradio.

Користувач може:
1.Завантажити зображення.
2.Натиснути кнопку «Показати зображення».
3.Отримати повідомлення про успішне завантаження.
4.Переглянути завантажене зображення.

 Основні елементи програми

Функція `show_image()`

Функція отримує завантажене зображення.

Якщо зображення не завантажене, користувач отримує повідомлення:

«Будь ласка, завантажте зображення.»

Якщо зображення завантажене, програма повертає повідомлення:

«Зображення успішно завантажено!»

та саме зображення.

Інтерфейс Gradio

Для створення інтерфейсу використано:

- `gr.Blocks()` — основний контейнер інтерфейсу;
- `gr.Markdown()` — заголовок;
- `gr.Image()` — поле для завантаження та відображення зображення;
- `gr.Button()` — кнопка;
- `gr.Textbox()` — поле для повідомлення.

 Обробка натискання кнопки

Після натискання кнопки викликається функція `show_image()`:

python
button.click(
    fn=show_image,
    inputs=input_image,
    outputs=[message, output_image]
)
