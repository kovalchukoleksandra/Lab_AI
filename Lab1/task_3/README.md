 Task 3 — Система розпізнавання образів з навчанням
Завдання
Створити систему розпізнавання образів з навчанням за допомогою нормованих векторів ознак.

У роботі використовується 3 класи, для кожного класу вводиться по 10 навчальних зразків.

Опис роботи
Програма створює вебінтерфейс за допомогою Gradio.

Користувач може:

1.Завантажити по 10 навчальних зображень для трьох класів.
2.Отримати абсолютний та нормований вектори для кожного зразка.
3.Переглянути навчальні зображення із сіткою 5×5.
4.Виконати навчання системи.
5.Отримати геометричний центр кожного кластера.
6.Завантажити невідоме зображення.
7.Отримати його абсолютний та нормований вектори.
8.Порівняти невідомий образ із центрами трьох кластерів.
9.Отримати результат класифікації.

Основна функція `calculate_feature_vector()`

Функція:

* переводить зображення у відтінки сірого;
* розділяє його на 25 областей;
* підраховує кількість чорних пікселів у кожній області;
* формує абсолютний вектор;
* формує нормований вектор;
* створює зображення із сіткою 5×5.

Функція `process_class()`

Функція обробляє навчальні зразки одного класу.

Для кожного зображення вона:

* обчислює абсолютний та нормований вектори;
* зберігає зображення із сіткою;
* додає нормований вектор до списку;
* обчислює геометричний центр кластера.

Геометричний центр кластера

Геометричний центр знаходиться як середнє значення всіх нормованих векторів навчальних зразків класу:
text
center = mean(normalized_vectors)


У програмі використовується:
python
center = np.mean(
    np.array(normalized_vectors),
    axis=0
)


Отриманий центр є еталонним вектором відповідного класу.

Функція `train_system()`

Функція виконує навчання всієї системи.

Вона:

* розділяє 30 зображень на три класи по 10 зразків;
* обробляє кожен клас;
* створює геометричний центр кожного кластера;
* зберігає центри для подальшої класифікації;
* повідомляє про завершення навчання.

Класифікація невідомого образу

Після навчання можна завантажити невідоме зображення.

Для нього створюється нормований вектор ознак. Потім він порівнюється з геометричними центрами трьох кластерів.

Для порівняння використовується евклідова відстань:

text
d(X,Y) = √Σ(xᵢ - yᵢ)²


Найменша відстань означає, що невідомий образ найбільш схожий на відповідний клас.

Функція `classify_unknown()` обчислює відстані до всіх трьох центрів і вибирає клас із найменшою відстанню.

Інтерфейс Gradio

Використано:

* `gr.Blocks()` — основний контейнер;
* `gr.Image()` — завантаження та відображення зображень;
* `gr.Gallery()` — відображення навчальних зразків;
* `gr.Textbox()` — виведення векторів і статистики;
* `gr.Button()` — запуск навчання та класифікації;
* `gr.State()` — збереження центрів кластерів між операціями.
